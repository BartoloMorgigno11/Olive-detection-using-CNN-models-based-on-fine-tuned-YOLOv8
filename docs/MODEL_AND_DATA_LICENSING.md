# Model and data licensing

## Dataset

The documented training source is [Olive Fruit Detection v1 on Roboflow Universe](https://universe.roboflow.com/aliasghar/olive-fruit-detection/dataset/1), published with a CC BY 4.0 label. Attribute the original dataset provider, link to the dataset and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), and identify modifications if redistributing adapted material. Verify provenance and rights in the underlying images independently where required. The exact dataset export is not included here.

## YOLO and model artifacts

The application uses Ultralytics 8.2.103. Its upstream [AGPL-3.0 license](https://github.com/ultralytics/ultralytics/blob/v8.2.103/LICENSE) and [licensing guidance](https://www.ultralytics.com/license) must be considered separately from rights in training images. The project claims no Enterprise license.

The fine-tuned model checkpoints are not included in this repository. Their exact provenance, licensing and redistribution scope must be established before sharing them or distributing an integrated model or service. Ultralytics' published guidance calls for complete corresponding source, including model weights where applicable. This repository does not claim that omission of weights automatically satisfies those requirements. Do not distribute or deploy an integrated version until the applicable obligations have been reviewed and satisfied.

If a modified covered program is made available for remote network interaction, comply with [AGPL section 13](https://www.gnu.org/licenses/agpl-3.0.html), including a suitable source offer to remote users where required. Review this against the exact deployed revision and its corresponding source.

The current repository is an educational local prototype, not a validated agricultural measurement service. No weights or dataset archives have been added as part of the license change.
